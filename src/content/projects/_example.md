# Example project write-up

Files in this folder named `<project-slug>.md` become that project's page text.
This file starts with an underscore, so it is ignored. Copy it, rename it to a real
slug (for example `bench-power-supply.md`) and edit.

## What markdown supports

Regular paragraphs, **bold**, *italic*, and [links](https://example.com) (external links open in a new tab).

- bullet lists
- and numbered lists
- inline `code`

> Block quotes work too.

## Images

Put the file in `public/images/` and reference it without a leading slash.
The alt text in the brackets is for screen readers.
